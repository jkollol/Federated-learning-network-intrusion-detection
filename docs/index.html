Project overview

The experiment asks how a centralized classifier compares with a simple federated alternative when data is split across clients with different attack-label mixes. It reports accuracy, precision, recall, F1, and an estimate of model communication.

01 · Prepare

Clean network flows

Read CICFlowMeter CSVs, map labels to benign or attack, handle invalid numeric values, and scale using training data.

02 · Train

Compare two approaches

Fit a centralized SGD classifier, then simulate synchronous FedAvg across seeded Dirichlet-partitioned clients.

03 · Evaluate

Measure quality and cost

Evaluate on a fixed holdout set and estimate model bytes uploaded and broadcast during federated rounds.

Evaluation status

Final results are pending. A local run completed, but scikit-learn emitted divide-by-zero, overflow, and invalid-value warnings during model computation. The scores are omitted from this public showcase until a numerically stable rerun is complete.

The experiment is designed to report accuracy, precision, recall, F1, and estimated communication. Communication counts float64 model parameters sent from each client to the server and broadcast back over each round; it excludes protocol headers, compression, retransmission, and optimizer state.

Run it on macOS

cd federated-ids
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install -r requirements.txt
python3 -m pytest -q
python3 -m src.run_experiment --data-dir data/raw --output-dir outputs

Download the CICIDS2017 machine-learning CSV archive separately and put the extracted CSV files in data/raw/. The dataset is not included in this repository.

Scope and limitations

This is a simulation

Clients are partitions of one local dataset. The project does not provide secure aggregation, differential privacy, malicious-client defenses, or real network transport.

Reproducible starting point

Seeds, client count, Dirichlet concentration, rounds, and local epochs are configurable. Results should be rerun and recorded with the dataset version and machine details.

Dataset and citation

Dataset source: Canadian Institute for Cybersecurity, CICIDS2017. Cite Sharafaldin, Lashkari, and Ghorbani, “Toward Generating a New Intrusion Detection Dataset and Intrusion Traffic Characterization,” ICISSP, 2018.
